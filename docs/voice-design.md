# 短剧配音方案（声音如何自然融入视频）

## 目标

- 不同角色有可区分、稳定的声线；
- 对白像真人交流，而不是一句一句念稿；
- 声音与画面、字幕、口型同步对齐，混在一起响度一致。

## 1. 声线：默认自动分配，可手动覆盖

| 情况 | 规则 |
| --- | --- |
| 角色库里填了 `voice` | 直接使用（Edge 音色名、OpenAI 音色名或 ElevenLabs `voice_id`） |
| 没填，描述里能看出性别/年龄 | 从对应供应商的音色池里挑性别、年龄最接近的，避开旁白音色 |
| 没填，也看不出特征 | 按名字哈希稳定分配，保证同一角色全片同一个声音 |

自动分配按整条脚本的说话人一次性完成（`allSpeakers`），同一角色跨分镜不会换声。
配音供应商决定音色池：Edge（免费）、OpenAI 兼容（`nova/onyx/...`）、ElevenLabs（voice_id）。

## 2. 合成：先按“说话轮次”，轮次内再按标点分句

同一角色连续说的台词会合并成一个轮次再合成（`mergeDialogueTurns`），
TTS 拿到完整上下文；轮次内部再按标点分句（`synthesizeSpeechPieces`），
句与句之间留呼吸，不会一口气念完。字幕再按原句字数比例切分，展示不受影响。

每句单独合成时，每句都有句尾收束，叠在一起就是“一字一字背书”的听感，这是主要问题。

## 3. 节奏：对白之间留停顿

- 首次开口 0.12s
- 同一人继续 0.18s
- 换人 0.32s

停顿写入音轨，字幕起点、分镜时长按含停顿的真实音轨重算，不会错位。

## 4. 语气：按角色与台词给提示

- 角色层面：性别、年龄 → 语速/音高微调（年长慢、年轻快、音高相应变化）；
- 台词层面：争执、疑问、哭腔、耳语、笑意 → 生成表演提示；
- OpenAI `gpt-4o-mini-tts` 走 `instructions`，ElevenLabs 用 `stability/style` 参数。

## 5. 混音与对齐

- 每句/每轮配音做 EBU R128 响度归一（`I=-18, TP=-2, LRA=7`），男女声混排不会一句大一句小；
- 口型同步（VideoRetalk）按音频驱动画面，`video_extension:false` 避免画面被拉长；
- 成片拼接前校验每个分镜都进入成片、时长与分镜合计一致。

## 6. 供应商选择建议

| 供应商 | 效果 | 成本 |
| --- | --- | --- |
| Edge TTS | 基础，稳定，但不支持情绪风格 | 免费 |
| OpenAI 兼容 `gpt-4o-mini-tts` | 支持 instructions，可按角色/台词语气表演 | 按量计费 |
| ElevenLabs `eleven_multilingual_v2` | 最接近真人演员，支持 style 起伏 | 按量计费 |
| 阿里百炼 `qwen-tts` / `cosyvoice-v3` | 国内直连、延迟低；音色复刻后的 voice id 直接可用 | 按量计费 |
| 百炼第三方模型（如 `MiniMax/speech-2.8-turbo`） | 走百炼原生 multimodal-generation 接口（`input.audio` + `parameters.voice`），用百炼 Key 即可 | 按量计费 |

要接近其他 AI 短剧的效果，建议 ElevenLabs 或支持 instructions 的模型；Edge 只能作为免费兜底。

## 已知限制

- 情绪判断基于关键词，复杂潜台词仍依赖模型本身的表演能力；
- 口型同步受平台返回时长影响，异常时长会触发字幕重排；
- 没有背景音乐/环境音轨，若需要需另加混音层。
